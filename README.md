# PROJEK-PABW-25523132-## Pertemuan 4 — Design Token Halaman Profil

- Berkas gaya yang dibuat: `tokens.css`, `base.css`, `layout.css`, `komponen.css`, `tema.css`
- Konsep warna: Warm Terracotta & Clay Slate (Bebas navy dan bebas hijau).
- Alasan pemilihan warna: Memberikan nuansa energik dan hangat untuk pencatatan olahraga, sekaligus memiliki kontras tinggi yang nyaman di mata.

### Token yang Ditetapkan
| Token | Nilai | Untuk Apa |
|---|---|---|
| `--color-primary` | `#B84318` (terang: `#FF9E79`) | Tombol, tautan, garis aksen |
| `--color-fg` | `#171311` (gelap: `#F3EFEA`) | Teks utama |
| `--color-bg` | `#FAF7F5` (gelap: `#171311`) | Latar utama halaman |
| `--color-surface` | `#FFFFFF` (gelap: `#231D1A`) | Panel form, kartu, dan tabel |
| `--color-focus` | `#C85A17` (gelap: `#FFB74D`) | Outline navigasi keyboard (:focus-visible) |
| `--radius-md` | `0.5rem` | Sudut tombol, kartu, dan kolom isian |
| `--space-4` | `1rem` | Jarak spasi standar |

Kriteria selesai: Mengubah `--terracotta-600` di satu baris `tokens.css` berhasil mengubah seluruh aksen halaman secara serempak.
